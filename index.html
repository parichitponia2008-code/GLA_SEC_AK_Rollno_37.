📊 Quick Comparison: while vs for vs do-while Loop

Most Important 1st-Semester Exam & Viva Table
Feature while Loop (Studied ✅) for Loop (Learn Next 🔜) do-while Loop (Learn Next 🔜)
Loop Type Entry-Controlled (checks condition at the start) Entry-Controlled (checks condition at the start) Exit-Controlled (checks condition at the end)
Minimum Executions 0 times (if condition is false initially, body never runs) 0 times (if condition is false initially, body never runs) At least 1 time (body runs once before condition is checked)
Syntax Structure init;
while (condition) {
  body; update;
}		 for (init; cond; update) {
  body;
}		 init;
do {
  body; update;
} while (condition);
Best Used When Number of iterations is not fixed in advance or reading until a condition stops Exact number of iterations is known beforehand (e.g., 1 to 100) You want a menu-driven program to run at least once before asking "Continue?"
Semicolon at End? No semicolon after while(cond) No semicolon after for(...) Yes! Ends with a semicolon: while(cond);
